# Blancall Windows 功能对等矩阵（Phase 0）

- 基准：Android `Blancall-Std 7.6.1-NoAI / vc54`（`D:\Blancall\Blancall-Std`）
- 产品范围：**只做无 AI 版**；无网络请求、无 INTERNET 能力、无遥测
- 对照：`Blancall Pro` 仅用于核对共享数据格式与备份结构；AI 功能不在 Windows 范围
- 状态：全部为 `未开始`。**未通过验收不得改为完成。**
- 复用列：A=原样复用 / B=薄改复用 / C=重写；同一功能含多层时按主要工作量标注。

## 0. 图例与总览

| 优先级 | 含义 |
|---|---|
| **P0** | 学习闭环必需；缺失则产品不成立 |
| **P1** | 完整 parity；缺失会被用户视为「不是 Blancall」 |

**D 区已知差异（需在 README 与设置页说明）**

1. Windows 新增 `record_id_seq`、`pre-import_*.zip`、`settings/`；不写入备份，Android 忽略。
2. Windows 对 `articles.json`/`records.json` 覆盖前留 `.corrupt-*` 副本（Android 不留）。
3. Windows 备份校验更严，会拒绝 Android 可能接受的畸形包（例如 `files/.`）。
4. `article_id_seq`、`fsrs_reviews.jsonl`、`reminder_state.json` 不进备份（与 Android 一致）。
5. Pro 备份中的 `ai` 类目会被忽略；不会写入 `ai_history`，也不会因此清理本地文件。
